# Baku Scuba — цены

Единый источник цен для сайта bakuscuba.com. Сайт читает `prices.csv` вживую —
правка цены здесь появляется на сайте без пересборки.

## Как редактировать
Открыть `prices.csv` → кнопка ✏️ (Edit) → поправить число в колонке `price` →
внизу «Commit changes». Через несколько секунд обновится на сайте.

## Формат
| колонка | что |
|---|---|
| `course_id` | id курса (совпадает с сайтом: `ow`, `aow`, `rescue`, …) |
| `format` | `group` (в группе) / `individual` (индивидуально) / пусто (единая цена) |
| `price` | цена как показывать: `$650`, `650 ₼`. Пусто → на сайте «Уточнить цену» |

Пустая ячейка цены = сайт покажет «Уточнить цену» + WhatsApp (не $0, не старое число).
